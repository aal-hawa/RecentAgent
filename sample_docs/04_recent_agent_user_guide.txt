RecentAgent User Guide (this file is indexed into the knowledge base)

RecentAgent is a demonstration AI agent that combines a Retrieval-Augmented Generation pipeline with a set of tools, orchestrated by a ReAct reasoning loop. This guide is part of the sample knowledge base, so you can ask the agent questions about itself and watch it answer from retrieved, cited documents.

What RecentAgent can do. It answers general questions with the underlying language model. It answers questions about uploaded documents by calling the knowledge_base_search tool, which performs vector search over indexed chunks and returns the most relevant passages together with their source names. It computes exact arithmetic with the calculator tool, which uses a safe AST-based evaluator rather than eval. It searches the public web with the web_search tool powered by DuckDuckGo and requires no API key. It fetches encyclopedia summaries with the wikipedia tool. It reports the current date and time with the current_datetime tool.

How the reasoning loop works. For every user question the agent writes a Thought describing its plan, then an Action naming one tool and an Action Input for it. The system executes the tool and returns an Observation. The agent repeats this up to the configured maximum number of tool rounds, then produces a Final Answer. Every step is displayed in the reasoning trace panel in the user interface, so the agent's behavior is fully transparent and inspectable.

How the knowledge base works. Uploaded PDF, TXT, Markdown, and DOCX files are converted to plain text, split into overlapping chunks of about one thousand characters, and embedded into vectors. Retrieval ranks chunks by cosine similarity between the question vector and chunk vectors. If neural embeddings are available, for example through a local Ollama model or OpenAI, the system uses them; otherwise it automatically falls back to TF-IDF lexical retrieval, which needs no downloads and works completely offline. Answers that use retrieved passages cite the source document, and the sources panel shows the exact chunks with their similarity scores.

Practical tips for good results. Ask specific questions rather than vague ones. For document questions, use words that appear in the documents. If the agent retrieves the wrong passages, rephrase with more distinctive terms. For current events, the agent should use web search; if the network is unavailable it will say so and answer from its own knowledge. The temperature setting controls creativity: keep it low, around zero point two, for factual and tool-driven work, and raise it for brainstorming. The maximum tool rounds setting controls how persistent the agent is before it must give its best answer with the information it has.

Configuration options. The sidebar selects the provider: Ollama runs everything locally and offline, requiring the llama3.1 chat model and the nomic-embed-text embedding model to be pulled; Groq offers a free API key and very fast inference; OpenAI offers GPT models and neural embeddings. Documents can be added by file upload or by pasting raw text, and each document can be deleted individually or the whole knowledge base can be cleared. The knowledge base persists to disk in the data directory, so indexed documents survive restarts. On Windows, start.bat launches the application and stop.bat stops it.
