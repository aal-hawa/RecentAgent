🤖 RecentAgent

An AI agent with RAG (document knowledge base) and tools, showing its reasoning live — web demo

⚠️ Testing demo only — not the product. This hosted version runs a simplified agent on a free-tier Gemini key and resets on cold starts. The full app runs locally with Streamlit (your documents stay on your machine).
ℹ️ About this demo

1. ReAct agent — Thought → Action → Observation loop implemented from scratch; every step is shown after each answer.

2. Tools — knowledge_base_search (RAG over 4 sample documents), calculator (AST-sandboxed), wikipedia, current_datetime.

3. RAG — chunking + TF-IDF vector search + cited answers, rebuilt for the web demo without heavy dependencies.

4. Differences vs the local app — no DuckDuckGo web search, no document upload, history resets when the demo goes cold.
