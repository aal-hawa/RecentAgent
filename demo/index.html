chevron_rightℹ️ About this demo

RecentAgent demonstrates a production-shaped AI agent:

1. RAG — upload → chunk → embed → vector search → cited answers
2. ReAct agent — Thought → Action → Observation loop (from scratch)
3. Tools — knowledge base, calculator (AST-sandboxed), web search, Wikipedia
4. Providers — Ollama / Groq / OpenAI behind one OpenAI-compatible client

This is the hosted web demo: the chat runs the same ReAct loop with Gemini, over pre-loaded sample documents. The real project is local-first — see README.md in the repository.

🤖 RecentAgent

An AI agent with RAG (document knowledge base) and tools (calculator, web search, Wikipedia) — built from scratch with an inspectable ReAct reasoning loop.
